# Memory Music product, privacy and support

Static, bilingual pages generated by `python3 build_site.py` into `docs/`.
The root is the bilingual product introduction. `python3 build_preview.py` also
maintains existing `/preview/` URLs. Privacy and support pages stay separate.
The site uses local CSS and a small accessible gallery/lightbox script, with no
external fonts, analytics or payment flow. Prices describe the approved US launch
plan; the app is clearly marked as preparing for release.

Product images render actual App widgets with a synthetic in-memory library.
Songs are fictional; abstract artwork is original. No private collection,
audio, database or application business source is published here.
The App is preparing for release; there is no active download or payment link.

Contact: kenapple9527@gmail.com

CarPlay: `/carplay/` and `/en/carplay/`, generated by `carplay_page.py`.
The hero is an original CSS feature illustration, explicitly not a vehicle
screenshot. The player image uses the existing real iPhone widget render.
Physical CarPlay release validation remains in progress. The homepage order is
preserved; its CarPlay card and footer link to the new page.

Native source materials: `/open-source/` and `/en/open-source/`, generated by
`open_source.py`. Only the sanitized native-component archive and full notices
are published in `assets/downloads/` and copied to `docs/downloads/`. Archive
SHA-256 is shown on both pages. `rebuild.py` inside the archive builds unsigned
macOS/iOS frameworks; it does not install or alter the application. The page
does not claim full-app replacement or distribution clearance.
