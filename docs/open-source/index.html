独立重建

在装有官方 Xcode 和 Python 3 的 Mac 上解压归档。选择一个尚不存在的输出目录，运行以下命令；路径中的占位目录请换成自己的位置。

python3 rebuild.py --platform macos --arch arm64 --output /path/to/new/mac-build
python3 rebuild.py --platform ios --arch arm64 --output /path/to/new/ios-build

工具只构建原生框架，并检查 24 个公开 C 接口；不签名、不安装、不联网，也不改动已安装的 App。macOS 还可指定 --arch x86_64；iOS 此配方面向 arm64 真机。最低构建目标为 macOS 14 / iOS 17。

可选 --marker 参数只在构建副本中改变版本字符串，用于核验实际加载的是修改版；不会改变指纹算法或归档中的原生源文件。

使用修改后的组件

旧版（32）通过动态框架加载该组件。macOS 路径为 Contents/Frameworks/chromaprint.framework/chromaprint，iOS 为 Frameworks/chromaprint.framework/chromaprint。适用的开源许可规定这些组件的使用、修改与调试权限，Apple 标准许可协议保留相关开源许可授予的权限。
