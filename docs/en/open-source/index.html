Standalone rebuild

Extract the archive on a Mac with official Xcode and Python 3 installed. Choose an output directory that does not already exist and replace the placeholder paths below with your own.

python3 rebuild.py --platform macos --arch arm64 --output /path/to/new/mac-build
python3 rebuild.py --platform ios --arch arm64 --output /path/to/new/ios-build

The tool builds the native framework and checks its 24 public C functions. It does not sign, install, access the network or modify an installed app. macOS also accepts --arch x86_64; the iOS recipe targets physical arm64 devices. Minimum build targets are macOS 14 and iOS 17.

The optional --marker flag changes only a version string in a build copy, helping verify that a modified library is actually loaded. It does not change the fingerprinting algorithm or native source files in the archive.

Using a modified component

Historical build 32 loads this component dynamically: Contents/Frameworks/chromaprint.framework/chromaprint on macOS, and Frameworks/chromaprint.framework/chromaprint on iOS. The applicable open-source licenses govern the components’ use, modification and debugging permissions; Apple’s Standard EULA preserves permissions granted by those licenses.

Build output is unsigned. A local installation requires your own lawful signing and provisioning arrangement and a separate copy. These historical materials do not assert completed full-app replacement, re-signing or distribution checks for build 32. The current candidate no longer includes this component.
