再了解一点

你可能还想知道。

里面有可以直接听的音乐吗？+

Memory Music 播放和整理你自己准备的本地音乐文件，不提供音乐曲库、音乐下载或流媒体订阅。

iCloud 会把音乐文件传到其他设备吗？+

Pro 同步标签、歌单、音乐记忆等整理信息，不上传原始音频。每台设备仍需准备自己的音乐文件；同步也不能代替原始文件备份。

订阅结束后，已有资料怎么办？+

已有标签、智能分类、记忆与其他资料保留，仍可使用、编辑和导出。超过免费数量时无法新建更多标签或智能分类，Pro 同步与 CarPlay 停止使用。

换设备后，怎样恢复 Pro？+

使用购买时的同一 Apple 账户，在 App 内选择“恢复购买”。它恢复的是有效的 Pro 权益；音乐文件和整理资料需要另行准备、同步或从备份恢复。

封面补全和音频指纹识别收费吗？+

这两项功能属于免费范围。在线查询需要网络，并受第三方服务的可用性与使用条件约束；音频指纹查询可能需要自行配置 AcoustID Client Key。
